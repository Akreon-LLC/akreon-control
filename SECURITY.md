# Security Policy

Please report suspected vulnerabilities privately through
[GitHub vulnerability reporting](https://github.com/Akreon-LLC/akreon-control/security/advisories/new).
If private reporting is unavailable, open an issue requesting a private contact
without including vulnerability details.

Include the affected version or commit, a minimal reproduction, relevant
platform/compiler details, and the potential security impact. Please allow
maintainers to assess the report and coordinate a fix before public disclosure.

Use regular GitHub issues for bugs without a security impact.
